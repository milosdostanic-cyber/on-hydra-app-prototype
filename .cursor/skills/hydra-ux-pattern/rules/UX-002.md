# UX-002: Table Link Colour

- **Category:** Table patterns / Colour
- **Status:** Approved (2026-11-10, Milos)
- **Standard:** Link-style text inside tables uses the DS token `Color/Primary/colorLink`, never
  `Color/Primary/colorLinkActive`.

## Applies when

Any text or icon inside a table that acts as a link or link-style action, at rest (default state):

- Clickable cell values (record name, file name, ID that opens a detail)
- Inline text actions in a row (View, Edit, Download, Manage, "Show more")
- Link-type buttons and dropdown triggers styled as links in the Actions column
- Table header links, toolbar links that belong to the table (e.g. "Clear filters")

## Does not apply

- An explicitly designed **pressed/active** state frame or variant (that may use `colorLinkActive`),
  and hover state frames (`colorLinkHover`).
- Non-link text in tables (`colorText`, `colorTextSecondary`, etc.).
- Status badges, tags and danger actions (`colorError`), which follow their own rules.
- Links outside tables (pages, cards, modals); not covered by this rule.
- Internals of DS components (only check overrides on the instance).

## Implementation

- Bind the fill of the link text/icon to `Color/Primary/colorLink`.
- Never use raw hex or a primitive palette variable (e.g. `blue-6`).
- Prefer the DS component variant/property that already uses `colorLink` over a manual fill override.
- Preserve instances; never detach.

## Validation (per candidate)

1. Is the node inside a table (table component, `Table / ...` instances, or a table-like column layout)?
2. Is it link-style text/icon in its default state? If it is a state demo frame (hover/pressed), skip.
3. Fill bound to `colorLink` → **Already correct**. Bound to `colorLinkActive` → finding.
4. Raw hex / primitive matching the link colour → finding (bind to `colorLink`).
5. Unsure if the element is a link or if the frame is a pressed-state demo → **Needs review**.

## Fix (only when explicitly requested)

1. Fill bound to `colorLinkActive` (or raw/primitive link colour) on a text or icon override:
   rebind the fill to `Color/Primary/colorLink`.
2. If the wrong colour comes from the main component or a DS variant, do not edit the DS:
   **Needs review** (DS gap).

After the fix: re-read the bound variable, confirm the instance is still attached, screenshot before/after.
