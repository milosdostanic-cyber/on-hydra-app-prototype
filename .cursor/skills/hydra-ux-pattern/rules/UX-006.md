# UX-006: Screen Minimum Height 970

- **Category:** Layout / Screen frames
- **Status:** Approved (2026-11-11, Milos)
- **Standard:** Every top-level screen frame is at least **970px** tall (`minHeight = 970`). Short
  screens (empty, loading, error, no-results states) grow to 970 with the shell (Sidebar, work area
  background) filling the full height. Taller screens keep hugging their content.
- **Reference:** BOM - RSFC, Cheat Sheet · Part Cross-Reference section `7560:210686`
  (e.g. "2.2 — Part Cross-Reference · No results", 1750 × 970).

## Spec

| Part | Value |
|---|---|
| Screen frame | Auto Layout vertical, height HUG, `minHeight = 970` |
| `Body` (shell row) | `layoutSizingVertical = FILL` |
| `Sidebar`, `Right Work Area` | `layoutSizingVertical = FILL`, so the sidebar and the page background reach the bottom |
| Modal overlay (absolute) | Resized to the full screen height |

970 is a frame-size rule, not a design token; it is the one allowed raw number here.

## Applies when

- Top-level screen frames (sidebar + topbar shell, 1750 wide or similar) in any module file.

## Does not apply

- Component frames, modal-only frames, mobile frames, documentation/annotation frames, cover pages.
- Screens already taller than 970 (no change).

## Implementation

- Set `minHeight` on the screen frame instead of a fixed height, so content can still grow.
- Make the shell children FILL vertically; never stretch content cards to fill the gap.

## Validation (per candidate)

1. Is it a top-level screen with the app shell? If not → skip.
2. Height ≥ 970 and `minHeight` = 970 (or content naturally taller with `minHeight` set).
3. Sidebar and work area reach the bottom edge (no empty strip).
4. Pass → **Already correct**; otherwise finding.

## Fix (only when explicitly requested)

1. `frame.minHeight = 970`; `Body`, `Sidebar`, `Right Work Area` vertical sizing FILL.
2. Resize any absolute overlay to the new frame height.
3. Re-check spacing to neighbouring frames in the section; resize the section if needed.
