# UX-010: Row Action Style

- **Category:** Tables / Actions
- **Status:** Approved (2026-11-12, Milos, "fix all" on audit findings BOM-NR-001 to 004)
- **Standard:** Every row action in a table is a DS `Button` **size=small, type=default**. A
  destructive action adds `danger=true` and is always last. At most 2 visible buttons; more go into a
  ⋯ kebab `Dropdown`. No text links, plain text or `primary` buttons as row actions. One row has one
  trigger per action (no second link elsewhere in the row that does the same thing).
- **Reference:** BOM - RSFC · "1.1 BOM entry point", Actions cell `Button` small default `danger`
  "Delete"; `Documentation/hydra-ux-patterns.md` §7.2 (User rule, 30 Oct).

## Spec

| Part | Rule |
|---|---|
| Button | DS `Button` `type=default`, `size=small`, no icons unless the label needs one |
| Destructive | `danger=true`, placed last (rightmost or last menu item) |
| Count | ≤ 2 visible buttons + ⋯ (`Button` icon only → `Dropdown / Menu`) |
| Cell | Frame `Table / Table cell`, horizontal Auto Layout, padding 12/16 (`paddingSM`/`padding`), gap `paddingXS`, primary axis MAX, bottom stroke `colorBorderSecondary` (same as BOM Hub). DS gap: `Table cell` has no button variant |
| Column | Placement, width and alignment per UX-004 |
| Duplicate triggers | Other cells (name, description) are not links to the same destination as the row button |

## Applies when

- Any table row action in every module file and in the prototype code.

## Does not apply

- Bulk action bars, toolbar buttons, modal footers.
- Links that open a different destination than the row action (e.g. an external product page).
- Content File Manager while working on BOM (`AGENTS.md`).

## Validation (per candidate)

1. Is the element a row action (last column / Actions)? 2. DS `Button` small default (danger if
destructive)? 3. ≤ 2 visible + ⋯? 4. No other link in the row doing the same thing?
All yes → **Already correct**; otherwise list each mismatch. Primary-styled emphasis actions
(e.g. "Add info") → **Needs review**.

## Fix (only when explicitly requested)

Replace link-style action cells with the BOM Hub cell pattern holding `Button` small default; resize
the column per UX-004; reset duplicate link text to `colorText`. Screenshot before/after.
