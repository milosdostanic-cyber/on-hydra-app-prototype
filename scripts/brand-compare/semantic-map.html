RSFC blue ramp — semantic tokens & where each one is used

Verified against node_modules/antd/es/*/style/*.js — one antd semantic token per shade, defined in primaryPrimitiveBlue.ts → semanticsFromRamp().

Shade Semantic token Used in (antd components)
Highest-traffic shade is #1, not #6. Through antd's derived controlItemBgActive, shade 1 paints every selected table row, selected option, and selected calendar day. If a rebrand "doesn't look applied" after changing the main color, shade 1 is usually the one still stale.
Info alerts are a separate scale on purpose. colorInfo* binds to antd Daybreak Blue (#1677FF), not this ramp — surfaces in Alert, Badge, message, Modal, notification, Progress, Result. An info message should not read as a brand statement.
Repo usage of each token in src/ (direct token.* references): colorPrimary 68 · colorPrimaryBg 24 · colorPrimaryBorder 12 · colorPrimaryBgSubtle 8 · colorPrimaryBorderHover 6 · colorPrimaryText 6 · colorLink 4. colorPrimaryHover and colorPrimaryBgHover are never referenced directly — they only reach the UI through antd's own component styles. colorPrimaryText* has zero antd consumers; it exists for application code only.
