Three things that change the sequence

1. One blue ramp, not three colours. Navy (#004173), ASC primary (#0073A5), and link blue (#00B9F0) are steps 7, 6, and 4 of the same Primary/primary-* ramp. You cannot “keep navy” and “remap the blues” without choosing a ramp strategy first.

2. Logo is not token-bound. Remapping colour variables does not update logo artwork. Logo = separate asset + component restructure workstream.

3. Figma Info ≠ repo Info. Figma aliases Color/Info/* to primary; repo uses Daybreak Blue. Reconciled 2026-09-17 — Figma Color/Info/* now aliases Daybreak Blue/blue-*, matching the repo. The same pass fixed Radio, which had used colorInfoText where Ant Design uses colorPrimary.

Recommended order

  1. Close blockers (external + design-led)

    Light Blue role, authoritative hex values, ramp strategy, heading mechanism, web fallback. Logo clear space for sidebar layout.

    Unblocks: colour remap, expanded sidebar header

  2. Logo + typography in Figma (parallel)

    No external blockers except sidebar layout. Typography ~50 bindings including Compact mode.

    Can start now

  3. Colour semantics doc → Figma variable edits

    Sign-off before any hex change. Remap primary + Info together. Add data-viz palette and tint levels.

    Depends on: step 1

  4. Brand devices + publish library

    Angle Graphic, Accent Bar, gradient. Freeze mapping, publish once, verify propagation.

    Depends on: steps 2–3

  5. Product files → QA → reverse audit

    Shell first. Content promo is a redesign, not recolour. Grep Figma for ASC strings, Cairo, legacy blues, old logo fills.

    Depends on: step 4 + copy naming rule (Product)

The three-blues problem

Navy, ASC primary, and link blue sit on one generated ramp. Reseeding for Light Blue can silently move Navy off #004173.

primary-4 #00B9F0 Remap primary-6 #0073A5 Remap primary-7 #004173 Keep primary-9 #002A4A ≈ shade
StrategyWhat happensTrade-off
Reseed rampNew RSFC blue becomes seed; all steps regenerateNavy may leave step 7 — must pin or relocate explicitly
Freeze rampKeep primary-* steps; remap only semantic aliasesLegacy blues stay in primitives; semantics do the work
Split rampSeparate navy ramp + interactive rampCleanest long-term; net-new primitive structure

Do not touch

Daybreak Blue, Sunset Orange, Dust Red, Gold, Yellow, Volcano/button palette, neutral ramp, spacing, radii, shadows — unless a deliberate parity exception is documented.
