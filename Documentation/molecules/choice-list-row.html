Choice List Row

One selectable row in a bordered list: a radio or checkbox, a label, an optional description and an optional trailing count (“3 parts”).

Decision

NewMedium priority Molecules · Data entry

Why

Content, Part Search and SPEC draw these rows by hand inside modal slots, with divider lines and selected tint. A plain Radio or Checkbox atom has no row padding, divider, meta or selected fill. OptionCard type=option is a standalone bordered card; these rows sit together in one shared list, so they are a separate, denser molecule.

Based on

none

Related

OptionCard (type option) for 2-4 rich, separate choices. Radio / Checkbox atoms for plain groups such as BOM 1.2. Table with row selection for multi-column data (Part Search variants).

Priority rationale

Reuse: 3 modules, 4 occurrences. Consistency: hand-built rows, SPEC rows misaligned. Effort: low-medium (control × state).
