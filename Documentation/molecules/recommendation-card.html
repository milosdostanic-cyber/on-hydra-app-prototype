Why

Hydra already has RecommendationCard (2017:1141) but it has no text properties, no description, a capitalised State=Rest/Hover/Resolved variant, and hard-coded tags. SPEC still uses its own local recommendation_card (8362:7673) on 4 screens, and no module uses the Hydra copy (0 instances found). Upgrading the Hydra set is cheap and safe: nothing breaks if its properties are renamed.

Related

FeatureCard is a product card with image and link button (Part Search category). OptionCard is for picking or starting a choice. Release Notes cards share purpose and structure, so they join as state default without status or meta.

Priority rationale

Reuse: 2 modules, 27+ cards on 3 verified screens. Consistency: SPEC local set and RN hand-built cards. Effort: low (upgrade an unused set).
