Verdict

Update 21 Oct 2026: the three approved fixes are done (secondary-action property, description, BOM 1.6 label); the extra Upload button is gone from 8 cards. Open: BOM 2.2 “Clear search”, the title size option, the loose instance and the draft frame. The original verdict follows.

Not ready to document or publish. The component is well built (auto layout, tokens, text styles, real nested atoms) and all 9 module links are correct. But one hard-coded button, “Upload BOM file”, has no property and appears in every instance, so 8 of the 9 cards do not match their module. Fix that first, add the description, correct the BOM 1.6 label, and decide on a size option. Then the Jira and Change Log documentation can follow.

Open questions

  • Size option for the title?

    Add size = page | section (page 24 px, section 16 px) as the 19 Oct plan proposed, or keep one 24 px title everywhere? I recommend the size option: BOM 2.12 / 2.13 and Content sit inside panels where 24 px is too loud.

  • Button order with two buttons.

    BOM 3.4 puts the primary button first; BOM 2.2 puts it last. Pick one rule for the block (Ant Design usually puts the primary action last in a row, but this block centres them). I recommend primary first, matching BOM 3.4 and the current build.

  • Should Admin adopt the block?

    RN Admin and CFM Receipts use the bare Empty atom with a 14 px caption and no description. Adopting the block gives them a real title. I recommend adopting it with the section size, and adding a one-line description where it helps.

  • “No results” states.

    The 19 Oct audit said search “not found” results should not use this block, but BOM 2.2 (Cheat Sheet · No Results) is in the build. It looks and works like the other empty states, so I recommend keeping it and removing that line from the guidance.

  • Loose instance and draft frame.

    Delete instance 1972:6073 and move or delete Frame 1 (1935:314)?
