File Upload Dropzone

A bordered drop area where the user picks or drops one file, then sees the chosen file, the upload progress or a clear error, all in the same place.

Decision

NewHigh priority Molecules · Data entry

Why

SPEC and three separate Admin areas (Release Notes admin, Lead Time Import, Knowledge Center) each draw this box by hand. SPEC, Knowledge Center and Lead Time even share the same layer structure (upload icon, title and hint, button), which shows it is copied between files. Hydra has no Upload page and no molecule for it, so a new molecule is the clean option. In code it maps to the Ant Design Upload.Dragger plus Hydra state content.

Based on

none

Related

Alert (the blue info line above the box in Knowledge Center and Lead Time stays an Alert, outside the molecule). Empty State Block is for empty lists, not for file picking.

Priority rationale

Reuse: 4 product areas, 12 occurrences. Consistency: 4 visual drifts today (border, icon tile, button type, radius). Effort: medium (6 states, but only one structure).
