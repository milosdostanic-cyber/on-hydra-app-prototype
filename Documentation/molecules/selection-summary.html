Decision

NewHigh priority Molecules · Data display

Why

Content, Part Search and BOM each draw this panel from plain frames inside modal slots. The anatomy is tiny and static (an eyebrow plus one to three value lines), so a new molecule is cheap and removes drift. It is not an Alert: it carries no status, it only echoes the selection.

Based on

none

Related

Alert is for status messages (the green “Selected file” / “Uploaded file” panels are Alerts). Attribute List describes one object with label/value pairs; Selection Summary lists what will be affected under one eyebrow.

Priority rationale

Reuse: 3 modules, 8 occurrences. Consistency: value style and padding drift. Effort: low (no states).
