 4. Gaps that properties cannot reproduce
 Id Gap 
 G1 Vertical height jump In vertical layout, default and hover are 164 px high, selected and disabled 156 px (the Text frame is 80 px vs 72 px). In a BOM Export row the selected card will be 8 px shorter than its neighbours. Fix in the component (same Text frame height in all states), not in Replace. 
 G2 Tag position is fixed The tag sits on its own line between title and description. The 20 Oct plan said "in the title row". Cheat Sheet uses the tag as the leading visual (left of the title); SPEC 02 shows it after the description. No property controls the position. 
 G3 Tag style The nested tag is Tag__Colorful blue (light). Cheat Sheet uses Tag__Checkable checked (solid primary, white text). SPEC 02 draws its own tag with a raw #e6f4ff fill, which matches Tag__Colorful blue. 
 G4 Coming-soon teaser look No muted or info look exists. The module teaser is a flat colorFillQuaternary panel without border or shadow, with a normal dark title and a right-aligned Link atom. OptionCard disabled greys the title and description, keeps the shadow, and its link is a plain text line on the left. 
 G5 Primitive icon colour BOM Hub Upload and the local set use the primitive Lime/lime-7. The Replace cards bind the same primitive; it does not switch in dark mode. No semantic token fits (BOM 4.1 uses colorSuccessHover for the Excel icon). 
 G6 Disabled icon not dimmed In every disabled variant the icon keeps its full colour (green in the component screenshot), while the text turns to colorTextDisabled. 
 G7 Selected and border colours differ from the modules BOM pressed = 2 px colorPrimary, no tint. SPEC 05 selected fill = colorFillQuaternary. SPEC unselected border = colorBorder. OptionCard uses 1 px colorPrimary + colorPrimaryBg for selected and colorBorderSecondary at rest. Harmonized on 20 Oct; listed so the module teams know what changes. 
 G8 Live BOM instances after publish 16 remote instances in BOM 4.1–4.4 still use the old axes (control = none, state = default or pressed). After publishing, swap the 4 pressed ones to selected, and check that the 12 default ones resolve to type = action, state = default. 
 G9 Link width in horizontal variants The hidden Link text keeps a fixed 185 px width in horizontal variants (the text column is 263–291 px). A longer link wraps earlier than the description. Check before more links are used.
