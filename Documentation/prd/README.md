# PRDs (product requirement documents)

Store **in-repo PRDs** here as Markdown when you want version control and PR diffs: e.g. `Documentation/prd/2026-05-bom-upload-destinations.md`.

- **Featured Parts:** [featured-parts.md](./featured-parts.md) (mirror + prototype decisions). **Implementation handoff (AI + you):** [featured-parts-implementation-brief.md](./featured-parts-implementation-brief.md).

Alternatively keep PRDs in an external system (Notion, Linear, Google Doc) and paste the **link plus a short ID** into the Cursor task so `@hydra-prd-ux-playbook` work can reference them.

When a PRD is **implemented and merged**, update **[../hydra-app-capabilities.md](../hydra-app-capabilities.md)** if routes, navigation, or adopted behavior changed.
